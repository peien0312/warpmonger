# 荷魯斯滾球 HORUS BALL — 遊戲設計文件

> 2026-07-30 整理，供 Unity 重製參考。現行實作：React Three Fiber +
> Rapier（web），程式在本目錄；後端 API 在 `../skeeball.py`（Flask）。
> **後端可直接沿用** — Unity 客戶端只要實作 §10 的 HTTP 合約即可接上
> 現有的會員/優惠券/排行榜系統。

## 1. 核心概念

夜市滾球（skee-ball）×柏青哥×打 Boss 的三幕式：

1. **滾球段**：瞄準→蓄力→發射，球衝上滑道飛向傾斜標靶板，進洞得基礎分
2. **落球段**：進洞與否，球都會掉進機台後方的落球軌道（三種可切換設計），
   途中穿過隨機獎勵圈圈累積加成
3. **終幕**：球撞上 HORUS 大光頭憤怒臉 —「洞分＋圈圈」轉成傷害數字，
   按 TIER 出特效；同局累積傷害讓臉逐漸鼻青臉腫；單球傷害太低會被嘲笑

一場 3 球。總傷害 = 正式分數（排行榜、獎品都用它）。

## 2. 流程 / 狀態機

`idle → aim → power → rolling →（每球）→ over`

- aim：擺動箭頭（正弦），點擊鎖定角度
- power：垂直力量表（三角波，1.6s 一個來回 0→100→0），點擊鎖定
- rolling：球活著的整段旅程（滾道＋落球軌道），結束條件見 §7
- over：3 球結束 → 結算畫面（傷害 count-up、煙火、獎品）

## 3. 操作

| 輸入 | 作用 |
|---|---|
| 點擊（畫面任意處） | 鎖角度 → 鎖力度 |
| 拖曳 / A・D | 環繞鏡頭（拖曳 >6px 判定為拖曳並吞掉 click，避免誤鎖） |
| ←→ / 畫面◀▶鈕 | 滾動中微調：側向推力 7 m/s²，**總 Δv 上限 2.6 m/s**（救球用，不能事後瞄準） |
| R | 棄掉卡住的球（以目前累積傷害結算） |

## 4. 世界與物理（單位：公尺，Y 向上，玩家在 -Z 看向 +Z）

- **重力 -22 m/s²**（地球重力在玩具尺度會顯得飄；-9.81 → -16 → -22 逐步調上來）
- 球：radius **0.4**、mass 2.5、friction 0.9、restitution 0.22、
  linearDamping 0.08、angularDamping 0.15（低角阻尼才有「滾動感」）、CCD 開
- 發射：速度 = minSpeed + power×(maxSpeed−minSpeed) = **14→26 m/s**；
  仰角極小（up 分量 = 0.04 + power×0.05，正規化後乘速度）— 平射，靠滑道拋起
- 瞄準角範圍 **±0.14 rad**（再大就只是撞溝槽的廢角度）
- 球道 lane：寬 4、長 12、厚 0.3；兩側溝槽牆高 0.5
- 滑道 ramp：長 3.5、爬升 2.2、**曲率 curve 0.45**（截面 y=rise·t^(1+2·curve)，
  分 14 段箱體）、與標靶板間隙 gap 1.0（球飛越）
- **標靶板 deck：後傾 0.62 rad（≈35°）**，高 4、板寬 = 球道寬+1。
  這是整個手感的關鍵：球「落在板上滾進洞」而不是「飛進垂直牆上的洞」
- 洞：板面圓形開口（rim 用 10 段小箱體圍成圓）＋穿透式口袋
  （四面短牆、**無後牆**，深 1.2，中段有計分 sensor）— 球計分後繼續掉落
- 金洞（300）上方有 **7 段擋護弧 backstop**（半徑 r+0.3、弧 140°、高 0.5、
  restitution 0.08）：衝到位的球被接住、卸速、漏進洞 — 把「到達」變成技術、
  「進洞」變成獎勵
- **巡邏門 sweeper**：發光金條 1.25×0.26×0.55，在板面 y=4.15 高度左右巡邏
  （振幅 = 板半寬−0.75，週期 4.6s，kinematic）— 防記憶參數：同樣的
  角度力度要看時機。碰撞出火花＋金屬聲

## 5. 關卡（標靶板佈局）— 4 套

共通鐵則：**別把洞放在更高價值洞的正下方**（下洞的 rim 會吃掉所有爬升球）；
**洞緣離板邊 ≥0.15**（開口切到板邊球會漏出世界）。座標：x 橫向、y 板面高度
（板底 y=rise=2.2 起算）。

### 經典聖殿 classic（預設）
| 洞 | 分 | r | x | y |
|---|---|---|---|---|
| 中央之門 | 50 | 0.85 | 0 | 3.0 |
| 左/右聖印 | 100 | 0.7 | ∓1.5 | 3.7 |
| 帝皇之眼 | 150 | 0.66 | 0 | 4.5 |
| 荷魯斯之眼 L/R | 300 | 0.62 | ∓1.85 | 5.2 |

模擬驗證：中央低力→50 穩、中央高力→150、瞄 ±0.08~0.10＋力 0.65-0.8→300、
滿力飛過頭。

### 雙子疑陣 decoy
中央 y3.2 是 **r1.0 的 10 分陷阱**（肌肉記憶殺手）；50 在兩翼(∓1.7, 2.9)；
100 (∓1.35, 4.3)；200 左上 (−0.95, 5.05)；300 右上 (0.95, 5.6) — 左右不對稱。

### 天梯試煉 ladder
**之字形階梯**（直排會被下層 rim 吃掉，物理上不可行）：
50(−0.75,2.9) → 100(0.75,3.6) → 150(−0.75,4.4) → 300(0.75,5.3)，兩翼 50(∓1.95,3.4)。

### 荷魯斯之怒 fury
無安慰獎：20 分陷阱×2 (∓1.05,3.0)、**300 在 y4.35 正中 — 就在巡邏門巡邏線上**
（最好到達、最難時機）、150×2 (∓1.15,5.25)。5 洞就好 — 洞太多會互相干擾彈道。

## 6. 落球軌道 — 3 套（可切換，未來隨機）

共通鐵則：
- **單一斜面，嚴禁多件拼接**（接縫=卡球死角；曾因集球板+斜道兩件式卡死）
- 集球面必須**覆蓋整個落球區**（z≈10–14.5、含板側溢出）
- 側牆要拉到甲板高度（≈11 高），否則板邊飛出的球會越牆出界
- 頂端擋牆**不得高出球道底面**（曾做成隱形圍欄擋住滾球）
- 接球面 restitution 0.05（死彈跳 — 5-8m 落差不彈飛）
- 落球區的停滯判定要放寬（速度<0.2 持續 3s 才棄；滾道上是 <0.55 / 1.2s）

### 柏青哥 pachinko
單一斜面：起點 z5 y−1.8、**傾角 0.34**、長 15；3 排交錯釘柱
（圓柱 r0.14 高 1.0，restitution 0.65）；5 個圈圈隨機散佈在
落點下游帶（板面座標 z 10.2–13.6）；HORUS 站在斜面末端。

### 漩渦大砲 funnel
- 漏斗：中心 (0,−2.2,12.6)，上緣 r5.8、底孔 r0.85、深 4，**28 片箱體牆板**
  拼成錐面（friction 0.12）；上緣發光圓環
- 底孔下接住球的槽 → **卡通大砲**：sensor 觸發後定住球 0.45s（歸零速度、
  關重力）→ 轟出 `v=(0,15,9)`（弧線正中臉部）＋爆炸音＋火花
- 圈圈：碗內隨機 3 個（貼錐面站立）＋**彈道上固定 2 個**（每砲必穿=保證煙火）
- HORUS 浮在 (0,−1.6,21)

### 音速迴圈 sonic
- 集球坡：z5 起、傾角 0.3、**長 11**（蓋滿落球區）→ V 型導板收窄進軌道
- 窄軌道寬 2.4（兩側發光護欄 0.55 高）、平面高 y−5.1
- 加速板×2（z16.4 / z22.4）：sensor 把球速設為 **17 m/s**（迴圈需求：
  入口 ≥ √(5·g·r) ≈ 15.9）＋青色 >>> 箭頭＋zip 音效
- **垂直迴圈**：圓心 z19.3、r2.3、22 段切線箱體＋兩側唇緣 —
  **必須放在落球區之外**（曾放在正下方被落球砸中外殼）
- 圈圈：集球坡 1、迴圈前 1、**迴圈頂點 1（倒掛收集=招牌時刻）**、迴圈後 1
- HORUS 在 (0,−3.0,25)

## 7. 球的生命週期結束條件

- 撞臉 sensor → 正常結算（傷害 = 洞分＋圈圈）
- 出界：y<faceY−4、z>29、z<−9、|x|>9.6
- 停滯 / 在滾道上倒滾（vz<−0.4 且 z<滑道頂 且 y>0）持續 1.1s → 棄球
  （帶著已累積傷害結算，顯示「半路陣亡」）
- 飛行總時限 14s
- R 鍵手動棄球

## 8. 傷害/計分 & Boss

- 傷害 tier（表現用）：<50 weak（灰）/ 50-99 plain / 100-199 blue /
  200-299 purple / **300+ gold**（大字號+金色+鐘聲）
- 撞臉：畫面中央砸入式傷害數字（scale overshoot → 上飄淡出 1.6s）、
  臉部後仰+壓扁+抖動（spring，衰減 3/s）
- **鼻青臉腫**：同局累積傷害 ≥250 → 黑輪+OK繃；≥600 → 雙黑輪+缺牙+腫臉
- **嘲笑**：單球傷害 <50 → 換嘲笑臉 1.5s＋哈哈哈音效＋隨機嗆聲
  （「就這樣？」「不痛不癢！」「你在搔癢嗎？」「哈哈哈哈！」）
- Boss 是**可替換設定**（`src/config/boss.js`）：貼圖組（3 階段＋嘲笑）、
  瘀傷門檻、嘲笑門檻、台詞。臉部貼圖是程序生成
  （`../scripts/gen_wh_textures.py` horus_faces）
- 圈圈：+10 藍 55% / +25 紫 30% / +50 金 15%；torus r0.62、sensor r0.34；
  吃到=消失+爆花+風鈴聲

## 9. 鏡頭（狀態機驅動，全部 lerp 滑動）

| 階段 | 機位 |
|---|---|
| idle/over（HOME） | pos (0,5.9,−9.6) lookAt (0,2.8,6.5) — 全景 |
| aim/power（AIM） | pos (0,3.0,−10.6) lookAt (0,2.6,10) — 球+箭頭+板全入鏡 |
| rolling 滾道段 | 追尾：pos=(b.x·0.5, b.y+2.2, b.z−4.5) lookAt 球 |
| rolling 落球段 | **側面轉播固定機位**平移跟拍（各軌道自帶座標），look target 平滑 lerp |
| 撞臉前 ~4m | 推近特寫機位（各軌道自帶） |

教訓：**初始鏡頭要顯式 lookAt**（3D 引擎預設看原點）；落球段鏡頭要拉高，
否則穿牆穿板。拖曳/按鍵隨時搶回手動控制並取消自動滑動。

## 10. 後端 API 合約（Flask 現成，Unity 直接沿用）

Base：`https://abbeystoys.com/api/skeeball`，Cookie session（會員登入）＋
封測允許名單（env `SKEEBALL_BETA_MEMBERS`）。

| Method | Path | 說明 |
|---|---|---|
| GET | /config | level（甲板佈局 JSON）、prizes（獎品表，無代碼） |
| GET | /user/balance | tokenBalance、freePlay |
| POST | /session/start | 扣 1 代幣（freePlay 不扣）→ {sessionId, nonce, maxBalls:3, expiresAt} |
| POST | /session/:id/roll | {rollIndex(1-based 連號), pinsHit, score=該球傷害, nonce, clientTs} |
| POST | /session/:id/complete | 伺服器重算總分→發獎（冪等）；回 {totalScore, golden, prize} |
| GET | /leaderboard | 近7天每人最佳，名字打碼，me 標記 |

防作弊（伺服器強制）：nonce = HMAC(session)；roll 連號；
單球上限 = 最大洞分+200（圈圈餘裕）；session 10 分鐘；roll 間隔 ≥500ms；
**總分永遠由伺服器由 rolls 重算**。金洞：單球 300 標記 golden → 頭獎券。
獎品：POS settings `skeeball_prizes` {tiers:[{min_score,code}],apex_code}，
發券走會員錢包（source=skeeball, source_ref=sessionId 冪等）。

## 11. 音效（全程序合成，Unity 可改用音檔）

click(鎖定)、launch(力度越大越長的 whoosh+低頻)、score(按洞分升調，300=五連
琶音+高頻閃)、ring(風鈴)、clank(巡邏門金屬聲，150ms 節流)、boost zip、
cannon boom、punch(按 tier 加重，gold 加鐘鳴)、laugh(三聲下行方波)、
pop(煙火)、gameOver(勝=上行/敗=下行)。設定：靜音開關存 localStorage。

## 12. 結算演出

- modal 彈入(spring) + 傷害 **count-up**(ease-out 0.9s)，字色按 tier
- ≥150：甲板上空煙火 3 發；≥300：金色 6 發＋金色紙花雨；領獎必紙花
- 0 分：🐢「被荷魯斯笑到不行…下場雪恥！」搖擺烏龜
- 新紀錄（localStorage per-browser）：🏆 新紀錄！

## 13. 視覺基調

Bloom（threshold 0.55, intensity 0.85, mipmap）+ Vignette(0.72) 是質感的
一半；所有重點物件用 emissive（洞圈、護弧、巡邏門、溝槽霓虹軌、板框、
圈圈、加速板）。星空+火燒雲 equirect 背景、鎢絲色點光打在標靶板和 Boss 上。
貼圖三張：crimson 球(旋轉可讀的橫帶)、鉚釘鐵板地(無縫)、星雲天空
（`gen_wh_textures.py` 可再生）。

## 14. 踩坑實錄（Unity 重製請直接避開）

1. 垂直標靶板 = 全靠飛行入洞 = 隨機感 → **傾斜板+滾動入洞**才有技術感
2. 洞不能疊在高價洞正下方；洞開口別切板邊
3. 落球區任何「多件拼接」都會卡球 → 單一斜面
4. 隱形碰撞體高度算錯（頂牆穿出球道）→ 球停在半路：牆的世界座標要驗算
5. 迴圈/障礙不能放在落球路徑正下方
6. 停滯偵測要分區調參（滾道嚴、落球區鬆），用**高度**判斷分區
7. 隱形隨機（偷偷偏移準心）= 玩家覺得被騙；**可見的移動障礙**（巡邏門）
   = 公平的隨機
8. 鏡頭是遊戲的一半：分階段機位+lerp；落球段用側面轉播視角
9. 大落差接球面用近零 restitution，否則彈飛越牆
10. 調難度用**無頭物理模擬掃描**（aim×power 網格，統計每洞命中）而不是手感猜
    — 本 repo `scripts/tune-sim.mjs` 的方法論可移植 Unity（Editor 模式跑
    物理場景批量投球）
